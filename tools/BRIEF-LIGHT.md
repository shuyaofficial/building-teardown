# 軽量版の追加ルール（エレベーター・自動ドアより小さく作る機構）

`tools/BRIEF-TEMPLATE.md` の契約はそのまま守る。そのうえで範囲を次まで絞る。

## refs.md も自分で作る
- `<name>/refs.md` を、エレベーター（`elevator/refs.md`）・自動ドア（`autodoor/refs.md`）と同じ形で書く。
- WebSearch / WebFetch で、メーカーの技術資料・業界団体の基準・JIS・国交省の告示など一次に近い出典を2つ以上つける。出典の無い数値は「仮定」と書く。PDF が読めないときは `curl` で落として `pdftotext -layout` で読む。
- 「検算」の数値は python で式を1回通してから書く。**その値をどこで測る量か（例: 戸側の機械出力／モーター入力、巻取り軸のトルク／モーター軸のトルク）と、効率を入れたかを各行に書く**（エレベーターと自動ドアの refs.md で、ここの取り違えが2回あった）。

## 範囲
- 自動ツアーは 30〜40 秒。視点は 3 つまで、分離は 2 つまで。
- 計器は「その機構の芯」になる 4〜6 個に絞る。グラフは1本。
- 検算テストは refs.md の検算をすべて。決定論のテストを1つ。
- `tools/` と `building-kit/` は読むだけで変えない（複数の機構を同時に作るとき、共有部分がぶつからないように）。live-check は既存の `--click` / `--watch` / `--within` で使う。

## 報告
`BRIEF-TEMPLATE.md` の報告の形に加えて、refs.md で「仮定」にした数値の一覧。
